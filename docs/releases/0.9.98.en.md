# Upcoming: Caramba Project 0.9.98

[← Documentation](../README.en.md) · [RU](0.9.98.md) | **ENG**

**This release is not published yet.** The previously published panel is 0.9.97. These notes
describe prepared changes; check
[Releases](https://github.com/semanticparadox/caramba-project/releases/latest)
for the version currently available.

The panel, installer, nodes, bot and all Connect apps share release version
**0.9.98**. The internal client build number is **112**.

- **Team.** Individual staff accounts, view/manage permissions and access
  revocation that ends previous sessions.
- **Traffic.** Up to 730 days of daily history, custom dates, user/device filters,
  a chart and CSV. Device, shared and unknown traffic remain separate.
- **Keys.** Batches of up to 5,000 single-use keys, TXT/CSV and unused-key revocation.
  Free preserves days until approval; keys for the same plan add time.
- **Messages.** Telegram preview, formatting, PNG/JPEG/GIF up to 5 MB, buttons
  and a test message to yourself.
- **Support.** Ticket saving does not wait for Telegram. The updated client can
  retry submission without creating a duplicate.
- **Editions.** Free: 3 VPN servers, 2 relays and 100 users without integrated
  payments. Full requires a separately arranged license.

Back up the database, settings and attachments before upgrading. Update the
panel first, then nodes and clients. Following database changes, a rollback
may require a compatible backup.

New traffic history accumulates after upgrading. Legacy shared connections
continue working; their past traffic cannot be attributed to devices
retroactively. There is no public iOS build in this release.

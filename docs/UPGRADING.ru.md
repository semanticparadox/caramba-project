# Обновление и резервная копия

[← Документация](README.ru.md) · [English](UPGRADING.md) | **Русский**

Доступен выпуск **0.9.98**. Команда обновления устанавливает опубликованную версию.

**Обновление сервера с нового адреса требует выпуска 0.9.98 или новее.**
Панель, установщик, узлы, бот и приложения Connect используют общий номер **0.9.98**.

## Перед обновлением панели

Прочитайте [примечания к выпуску](https://github.com/semanticparadox/caramba-project/releases/latest).
Выберите время, когда краткий перерыв в работе меньше затронет пользователей.

Сохраните резервную копию базы данных, настроек установки, ключей и загруженных
вложений сообщений. Если меняли расположение файлов, включите эти каталоги
в копию. Для 0.9.98 каталог изображений и GIF по умолчанию —
`/var/lib/caramba/message-media`.

Храните копию отдельно от обновляемого сервера. Убедитесь, что знаете, как
восстановить её: после изменения структуры базы возврата одного старого
исполняемого файла может быть недостаточно.

## Обновите панель

На сервере панели скачайте актуальный
установщик из **Caramba Project**:

```bash
curl -fsSL https://raw.githubusercontent.com/semanticparadox/caramba-project/main/install.sh -o /tmp/caramba-install.sh
sudo bash /tmp/caramba-install.sh --upgrade
```

Этот путь подходит и для установок, которые получали обновления со старого адреса
`semanticparadox/caramba`: сначала обновляется установщик, затем компоненты.
Используйте новый адрес при следующем обновлении.

Автоматического перенаправления со старого репозитория нет. Старый установщик
0.9.97 обращается к нему, поэтому одного запуска старой команды обновления
недостаточно — нужен новый скрипт выше.

## Перенесите ссылки скачивания в панели

В **Bot & App → Client App** откройте форму **Downloads**. Если в полях Android,
Windows, macOS и Linux сохранены ссылки на старый репозиторий, замените их на:

| Платформа | Новый адрес |
| :--- | :--- |
| Android | `https://github.com/semanticparadox/caramba-project/releases/latest/download/Caramba-Connect-Android-arm64.apk` |
| Windows | `https://github.com/semanticparadox/caramba-project/releases/latest/download/Caramba-Connect-Setup-x64.exe` |
| macOS | `https://github.com/semanticparadox/caramba-project/releases/latest/download/Caramba-Connect-macOS-arm64.dmg` |
| Linux | `https://github.com/semanticparadox/caramba-project/releases/latest/download/Caramba-Connect-Linux-x64.tar.gz` |

Не добавляйте ссылку iOS: публичной сборки нет. Сохраните форму и проверьте кнопки
скачивания у пользователя.

**Смена адреса и смена сборки — разные действия.** Если по новому адресу лежит тот же
самый файл, достаточно заменить ссылку. Если переходите на другую сборку, например
Connect 0.9.98, сначала разместите на панели её соответствующие файлы
`Caramba-Connect-<platform>.json`. При локальной раздаче замените и сами приложения.
Версию, номер сборки и контрольную сумму панель берёт из этих файлов даже тогда,
когда адрес скачивания изменён вручную. Старый файл версии вместе с новым
приложением может вызвать ошибку проверки обновления.

В стандартной установке эти файлы находятся в
`/opt/caramba/apps/caramba-panel/downloads/`. Если при установке выбрали другой
каталог, используйте в нём папку `apps/caramba-panel/downloads/`. Берите приложения
и файлы версии из одного выпуска. После обновления проверьте **Bot & App →
Client App → Releases → Builds on disk**: отсутствующий в выпуске файл не заменяет
автоматически старый. Загрузка файла в Telegram не обновляет эти данные панели.
При ручной замене файлов дождитесь обновления кэша — до 5 минут — или перезапустите
панель в запланированное время. В списке должна появиться версия **0.9.98, сборка 112**.

Не меняйте только число версии вручную. Установленные приложения получают ссылки
от панели: переустановка приложения только для смены адреса не требуется.

## Проверьте сервис после обновления

Сначала обновите панель, затем обслуживающие VPN-серверы и релэи, затем приложения.
После завершения проверьте вход владельца, состояние серверов, тестовое подключение
и открытие подписки. Если используете Full, проверьте действительность лицензии
и работу оплаты до возобновления продаж.

## Что учитывать в 0.9.98

- История трафика до 730 дней начнёт накапливаться после обновления. Удалённые
  раньше данные не появятся заново.
- Точный учёт по устройствам появится после обновления клиента и применения
  конфигурации сервером. Общий трафик старых подключений остаётся общей категорией.
- Во Free пользовательские ключи и ожидающие подписки требуют одобрения
  администратора. Дни ключей сохраняются на время ожидания.
- Встроенный приём новых платежей требует Full. Изменение редакции не удаляет
  существующих пользователей и серверы.

## Обновите Caramba Connect

Используйте предложенное приложением обновление или скачайте новую сборку
[для своей платформы](../README.ru.md#скачать-caramba-connect). Закройте приложение
перед заменой файлов. На Android устанавливайте APK той же архитектуры поверх
приложения; не удаляйте его заранее без необходимости.

Если обновление не удалось, сохраните текст ошибки и номер версии, не повторяйте
удаление данных. Напишите [@caramba_support](https://t.me/caramba_support).
